# 🚨 AI Disaster Response & Emergency Intelligence Platform

## 🚀 Overview

An AI-powered emergency intelligence platform that predicts disaster risks, monitors crisis situations, and generates explainable emergency response insights using predictive analytics, RAG, and multi-agent architecture.

---

## 💡 Features

- Disaster risk forecasting
- Emergency response analytics
- Explainable AI insights
- RAG-powered crisis intelligence
- Multi-agent coordination
- Streamlit dashboard

---

## ▶️ Installation

pip install -r requirements.txt

---

## ▶️ Run Project

streamlit run app.py
